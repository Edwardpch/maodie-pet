## 关键特征（复刻时要保留的）

1. 全程**只用后腿直立**，像人一样走，不是四脚走。
2. 前爪位置有变化：走路时收在胸前 → 站定时交叠抱拢 → 抬起来竖中指。
3. 竖中指是**拟人化的五指手**，中指单独伸出，其余四指弯曲。
4. 节奏：走近（约 2.5 秒）→ 停顿亮手势（约 1 秒）→ 转身跑掉（约 2 秒）。
5. 情绪：面无表情、冷淡，挑衅感来自手势和歪头，不是龇牙。

## 需要注意的坑

- 原片 784×720 不是 16:9，也不是方形；要做桌宠素材得重新构图成方形绿幕。
- 原片最后猫跑出画面、越跑越小；桌宠素材不能用这段结尾，应改成"转身 → 回到站姿"。
- 原片 30fps、动作快；桌宠素材转 12fps 时，跑动段会顿，建议跑动只保留 1–2 拍。
- 原片背景是真实街景，若直接沿用，抠像会很难；做素材必须换纯色绿幕。

## 手势怎么写：翻手 vs 静态

**结论：写"掌心朝镜头"这种静态朝向，别写"翻手"。**

- 翻手 = 手腕从内向外转半圈，手指要在整段运动里保持同一手型。模型最不擅长的就是"运动中不散架"，写了翻手十有八九糊成一团或多长手指。
- 原片那一拍本来也不是"先看手背再翻过来"：它就是掌心朝镜头、四指弯着收拢、中指单独竖起来。
- 三条有效约束：① 开头就写"掌心朝向镜头"；② 写"手腕保持不动"防抖；③ 写"定格约 1 秒"稳住画面。

### 视频版（替换原 6–8 秒那句）

```
6–8 秒，猫抬起右前爪举到脸侧：从抬起开始掌心就朝向镜头，五指结构清晰，中指笔直向上，其余四指弯曲收拢贴向掌心，手背和手指覆盖橘色短毛；举起后手腕保持不动、定格约 1 秒，猫歪头，眼神冷淡挑衅。
```

### 一定要"先手背再翻过来"的写法（成品率低，慎用）

```
抬起右前爪举到脸侧，先手背朝向镜头、四指收拢；随后手腕向外缓慢翻转半圈，变成掌心朝向镜头、中指笔直向上，翻转过程约 0.4 秒，翻转结束后保持不动 1 秒；翻转过程中五指数量不变、不出现多余手指。
```

桌宠素材尤其建议用静态版：转 12fps 再抽帧后，0.4 秒的翻转只剩约 5 帧，手指会糊成色块。
