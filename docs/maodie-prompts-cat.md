# 橘猫「耄耋」新动作生成清单（豆包图生视频）

现有的 6 个动作（待机 / 睡觉 / 走路 / 开心 / 被摸 / 哈气）不动。下面 20 条是**新动作**，每条都是一段可直接粘贴的提示词，生成 10 秒绿幕视频，再由脚本自动转成透明 webm 接进桌宠。

## 三步走

1. **参考图**：`D:\project\dsh\pet-src\maodie-ref.png`（从「待机」帧导出，白底，512×512）。豆包选「图生视频」，上传这张图。
2. **生成**：粘贴下面任意一条提示词 → 时长选 10 秒 → 下载 mp4，按「动作名.mp4」命名，放进 `D:\project\dsh\pet-src\`。
3. **导入**：在 `D:\project\dsh` 下运行

   ```
   node maodie-import.mjs pet-src --register
   ```

   然后桌面端右键宠物 →「重载配置」（或刷新页面）。新动作会进入「小动作 / 生气 / 点击回应」分类，按权重混播。

## 生成前必看（决定抠图成败）

- 绿幕必须是**纯 #00FF00**：不能有渐变、地面、影子、边框、杂物；猫身上不要出现绿色。
- **首帧背景也必须是绿幕**：参考图是白底，只借用猫的外形，不要连白底一起生成。
- **关掉声音**：桌宠不需要音频，生成时选静音/无声，省时间也避免影响画质。
- 猫**全身必须留在画面内**，四周留一圈绿边——出画的部分会被直接裁掉。
- 先做 3 条试水，检查转出来的边缘有没有绿边、黑边；有问题多半是绿幕不纯或打了光。
- 每条 10 秒，**最后 1 秒要回到第一帧的站姿**，循环播放才不跳。
- 道具（杯子、纸箱、键盘、蝴蝶、激光点）一律「无→有→无」：先半透明虚影约 0.5 秒凝实，结束前 0.5~1 秒化光点消散，首尾帧保持干净。

## 动作与分类对照

| 动作 | 建议分类 | 触发方式 |
| --- | --- | --- |
| 舔毛、踩奶、追尾巴、揣手手、打哈欠伸懒腰、东张西望、扒拉杯子、钻进纸箱、打滚晒太阳、抓激光笔、偷吃被抓住、洗脸、扑蝴蝶、看鸟、踩键盘、翻肚皮 | 小动作 | 随机混播（权重 20） |
| 炸毛、飞机耳 | 生气 | 生气分类（权重 10） |
| 蹭头撒娇、伸爪拍屏幕 | 点击回应 | 点宠物时播放 |

「点击回应」不是分类，是 `animations.clicks` 数组：想点宠物时播「蹭头撒娇」，就把动作名手动加进 `maodie-config.json` 的 `animations.clicks`，例如 `["开心", "被摸", "蹭头撒娇"]`；想让它也随机混播，就再写进「小动作」分类。

## 生成后的检查

- 每条视频应 ≈ 512×512、10 秒、VP9-alpha；脚本会打印 `alpha=1`，没打印就是绿幕不纯，重生成。
- 单条体积一般 200–500KB，20 条约 5–8MB，桌宠内存压力可接受。
- 想删某个动作：删 `maodie-animation\<动作名>.webm`，再从 config 里去掉名字。
